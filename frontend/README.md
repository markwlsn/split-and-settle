# Split & Settle — Frontend (React + Vite + Tailwind CSS)

Modern, mobile-first web interface for **Split & Settle** — intelligent receipt splitting and debt settlement powered by Google Gemini Vision and Supabase.

---

## Features

- **Auth View**: Sign in & Sign up with seamless session management.
- **Group Hub**: Active groups, 6-character invite code badges, and quick modal actions.
- **Receipt Scanner & OCR**: File drag-and-drop or camera capture with Gemini Vision line-item extraction.
- **Interactive Split Matrix**: Clickable member avatar pills on each item, one-click "Split All Equally", and penny reconciliation indicators.
- **Balances & Settle Up**: Simplified debt cards ("Bob pays Alice $15.00") and direct payment recording.
- **Spending Analytics & Activity Feed**: Category charts, top merchants, per-member metrics, and live chronological audit logs.

---

## Quickstart

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

Open: **`http://localhost:5173`**

*(Make sure your backend is running on `http://localhost:5000`)*

### 3. Production Build
```bash
npm run build
```
